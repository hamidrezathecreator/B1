# Bogen Animation
## UI and geometric animation system for Unity 3D

This package contains various UI animations and geometric animations to create animations for Models, Camera, 3D UI etc. You can also create your own animation and motion scripts using this package.

## Features

- Various built-in UI animations based on Unity UI System (such as Alpha Animation, Position Animation, Rotation Animation, Color Animation etc.)
- Built-in ellipse motion (usable for camera, orbital motions, 3D UI etc.)
- Extensible UI animation (you can extend BaseAnimation class and write custom UI animations)
- Extensible motion system (you can create your custom geometric motions)
- Built-in "Toggle Panel" to manage UI panel smooth show/hide in an optimal way (automatically disable the game object when it's hidden)
- Built-in UI animation SFX (The SFXs play according to the animation's state)

## Components

Animation components:

- Local Position Animation
- Local Rotation Animation
- Local Scale Animation
- Transform Animation
- Canvas Group Alpha Animation
- UI Alpha Animation
- Material Alpha Animation
- Image Color Animation
- Emission Color Animation
- Mesh Color Animation
- TextMesh Color Animation
- Light Intensity Animation
- Rect Dimension Animation

Motion Components:

- Ellipse Motion
- Ellipse Auto Motion

Miscellaneous:

- Toggle Panel
- Animation SFX
- Blink Mesh
- Rotate Around Self
